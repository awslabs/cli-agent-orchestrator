# `cao-ag-ui-builder` — a CAO Agent Plugin

Emit-side AG-UI vocabulary for CLI Agent Orchestrator: the six allow-listed generative-UI components (approval_card, choice_prompt, diff_summary, progress, metric, agent_card) an agent sends with emit_ui, carried as CUSTOM `cao.generative_ui` frames. Describes CAO `main`; no released version carries this yet (#1198). Needs a local cao-server with the [agui] extra. No mcp.json.

Generated by `scripts/build_agent_plugin.py` from the canonical skills in
`skills/`. Do not edit by hand — `make check-agent-plugin` fails on drift.

## Install

Installing an agent plugin runs untrusted code and content from its source. This
package comes from the CAO repository itself, but the same statement applies to
every plugin you install from anywhere.

From a clone:

```bash
cao plugin add ./agent-plugin/cao-ag-ui-builder
```

From GitHub, without cloning:

```bash
cao plugin add https://github.com/awslabs/cli-agent-orchestrator --subdir agent-plugin/cao-ag-ui-builder
```

Any [Agent-Plugins-compatible](https://agent-plugins.org/specification) client can install this directory
the same way.
