# `cao-agent-plugin-lifecycle` — a CAO Agent Plugin

Skills for the Agent Plugins 1.0.0 package lifecycle: author a new package from an empty directory (the plugin.json manifest, skills/ and an optional mcp.json), and audit an existing one against the vendored schemas and the Agent Skills limits that CAO's own validator does not check. The audit skill bundles a validator that needs no CAO install and opens no network connection itself; its first run needs its dependencies available.

Generated by `scripts/build_agent_plugin.py` from the canonical skills in
`skills/`. Do not edit by hand — `make check-agent-plugin` fails on drift.

## Install

Installing an agent plugin runs untrusted code and content from its source. This
package comes from the CAO repository itself, but the same statement applies to
every plugin you install from anywhere.

From a clone:

```bash
cao plugin add ./agent-plugin/cao-agent-plugin-lifecycle
```

From GitHub, without cloning:

```bash
cao plugin add https://github.com/awslabs/cli-agent-orchestrator --subdir agent-plugin/cao-agent-plugin-lifecycle
```

Any [Agent-Plugins-compatible](https://agent-plugins.org/specification) client can install this directory
the same way.
